Manual de instalação

Como instalar a GerencIA de ponta a ponta: o servidor (coletor + IA local) e as estações dos usuários (agente + extensão), com verificação e solução de problemas.

Visão geral — o que vai onde

ComponenteOnde rodaPara quê
ColetorServidor (Mac/Linux, on-premise)Recebe as capturas, resolve identidade, aplica o motor, serve o painel
Qwen3 (llamafile)ServidorClassificação de conteúdo Nível 1, local — o conteúdo não sai
AgenteEstação Windows (serviço)Detecta uso de IA em qualquer app (metadado), sobe no boot
ExtensãoNavegador da estaçãoCaptura o conteúdo (prompt + resposta) no navegador
Host nativoEstação (por usuário)Informa à extensão o usuário logado no Windows

Pré-requisitos

  • Servidor: Python 3.9+ (o coletor roda sem pip install). Para o Nível 1: ~2,7 GB livres (llamafile + Qwen3).
  • Estação: Windows 10/11, acesso de administrador, Python 3.9+ (o instalador do agente instala se faltar).
  • Rede: as estações precisam alcançar o servidor (ex.: http://10.211.55.2:8765 ou http://macbook-pro.local:8765).

Parte A — Servidor (on-premise)

1

Subir o coletor

Na pasta do projeto, exposto à rede das estações:

cd ~/Downloads/espia # processa a base e monta o painel (1ª vez) python3 run.py gerar # sobe o coletor aberto à rede (recebe das estações) ESPIA_BIND=0.0.0.0 python3 run.py coletor

O painel fica em http://127.0.0.1:8765/ (local) e, das estações, no IP/nome que o startup imprime.

2

Instalar e subir o LLM local (Nível 1 · Qwen3)

bash llm-local/instalar-llm-local.sh # baixa llamafile + Qwen3 (~2,7 GB) bash llm-local/rodar-llm-local.sh # sobe o modelo em 127.0.0.1:8090

O coletor encontra o modelo sozinho. Deixe os dois rodando (coletor + llamafile).

Cascata de classificação: Nível 0 detectores (CPF/CNPJ/Luhn) → Nível 1 Qwen3 local (conteúdo não sai) → Nível 2 nuvem (só o resíduo). Cada captura grava classificado_por.

Parte B — Estação Windows · Agente (serviço)

1

Baixar, extrair e instalar (PowerShell como administrador)

cd $env:USERPROFILE\Downloads Invoke-WebRequest "https://raw.githubusercontent.com/lucibad/espia-starkbank/main/borda/pacotes/GerencIA-Agente-Estacao.zip" -OutFile GerencIA.zip Expand-Archive GerencIA.zip -DestinationPath C:\GerencIA -Force cd C:\GerencIA\GerencIA-Agente-Estacao\servico powershell -ExecutionPolicy Bypass -File .\instalar-servico.ps1 -Coletor "http://10.211.55.2:8765" -Senha "UmaSenhaQueVoceLembre"

O instalador acha/instala o Python, instala pywin32/psutil, registra o serviço (início automático), endurece a ACL e guarda a senha.

2

Conferir

Get-Service GerenciaSensor | Select-Object Name,Status,StartType

Deve mostrar Running / Automatic. O agente registra uso real (~1×/dia por ferramenta), sem conteúdo.

Guarde a senha. Esqueceu? Como admin, .\resetar-senha.ps1 redefine sem precisar da antiga.

Parte C — Estação Windows · Extensão (conteúdo)

1

Baixar e registrar (atualizador, por usuário)

O atualizador baixa a extensão, confere a build e registra o host nativo de identidade para o usuário logado:

cd $env:USERPROFILE\Downloads Invoke-WebRequest "https://raw.githubusercontent.com/lucibad/espia-starkbank/main/borda/extensao/ATUALIZAR-EXTENSAO.ps1" -OutFile ATUALIZAR-EXTENSAO.ps1 powershell -ExecutionPolicy Bypass -File .\ATUALIZAR-EXTENSAO.ps1

Deve imprimir versao: 0.2.2, captura conteudo: SIM.

2

Carregar no navegador

Edge/Chrome: edge://extensions → Modo do desenvolvedor → Remover o antigo → Carregar sem pacote → C:\GerencIA\extensao (deve aparecer 0.2.2).

Firefox: about:debugging → Este Firefox → Carregar extensão temporária → selecione C:\GerencIA\extensao\manifest.json. Depois, em about:addons → Permissões → ligue o acesso aos sites (no Firefox a permissão de rede é manual).

3

Confirmar e testar

Feche e reabra o navegador (para reler o host nativo) e dê F5 na aba da IA. No popup da extensão: Agente conectado e Usuário com o nome real. Faça uma busca no ChatGPT e veja o conteúdo no painel → Captura → Conteúdo capturado.

Identidade multiusuário: o ID da extensão é fixo (chave no manifesto). Cada usuário do Windows roda o ATUALIZAR-EXTENSAO.ps1 uma vez (registra o host nativo no perfil dele) — e aparece com o próprio nome.

Verificação de ponta a ponta

  • Painel → Captura: a tabela Usuário × IA mostra a busca, com Origem (Extensão/Agente), Classificação (Detectores/Qwen3) e o vínculo ↔ prompt + resposta.
  • Card Conteúdo capturado: o texto digitado e a resposta da IA.
  • Vista Rastrear: busca reversa da informação.

Solução de problemas (os casos reais)

SintomaCausa / solução
“Python was not found” (abre a Store)É o atalho falso da Store. O instalador baixa o Python do python.org; ou instale manualmente e rode de novo.
“a execução de scripts foi desabilitada”Rode com powershell -ExecutionPolicy Bypass -File … (o INSTALAR.bat já faz isso).
“IdentityNotMappedException” na instalaçãoWindows em português — já corrigido (ACL por SID). Use o pacote atual.
Rodou de \\Mac\Home e o serviço não sobe no bootPrecisa de caminho local — o INSTALAR.bat copia para C:\GerencIA automaticamente.
Extensão: “Usuário não identificado”Host nativo não registrado para o ID. Rode o ATUALIZAR-EXTENSAO.ps1 e reabra o navegador.
Firefox: “Agente sem conexão”Permissão de rede do Firefox é manual: about:addons → Permissões → ligar acesso aos sites.
Agente gerando centenas de capturas/diaVersão antiga. Reinstale: dedup por uso (8h) + cache de DNS como autoridade (sem falso-positivo de CDN).
Esqueci a senha do serviço.\resetar-senha.ps1 (como admin, sem a antiga) ou sc delete GerenciaSensor e reinstale.

Implantação em massa (GPO / Intune)

Para muitas estações, use a pasta deploy/ do pacote do agente (instalação silenciosa):

  • gerar-hash-senha.ps1 — pré-hasheia a senha (não trafega em texto).
  • instalar-silencioso.ps1 — instala sem prompts, com código de saída; copia para C:\Program Files\GerencIA.
  • detectar.ps1 — regra de detecção do Win32 app no Intune. desinstalar-silencioso.ps1 — remoção central.

Passo a passo completo em deploy/LEIA-DEPLOY.md (dentro do pacote).

Camadas, em resumo: Agente = presença (metadado, qualquer app). Extensão = conteúdo (navegador). Proxy MITM (opcional) = conteúdo de qualquer app, só com aval de Segurança. O conteúdo é classificado on-premise pelo Qwen3; a nuvem é exceção.
