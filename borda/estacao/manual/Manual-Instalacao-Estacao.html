Guia de instalação · máquina do usuário (cliente)

Agente de estação
como serviço do Windows

Como instalar o sensor de rede do GerencIA numa máquina de usuário para que ele suba automaticamente com o Windows, reinicie sozinho se cair e só possa ser pausado ou desinstalado com senha.

O que o agente faz

O agente registra, para governança, quando a máquina fala com uma ferramenta de IA — de qualquer programa, não só do navegador (app de desktop, Cursor, um script, o Copilot do Windows). Ele soma três sinais, nenhum deles intercepta tráfego: um índice dos IPs das IAs, o cache de DNS do Windows e o processo dono da conexão.

O que ele vêO que ele NÃO vê
Que a máquina abriu conexão com um endpoint de IA, e qual ferramenta. O conteúdo — o tráfego é TLS (cifrado).
Qual processo abriu (ex.: cursor.exe, chrome.exe). O texto do prompt ou a resposta da IA.
O usuário logado no Windows e o nome da máquina. Ler o conteúdo exigiria interceptação (MITM) — este agente não faz.
Complementar à extensão. A extensão de navegador vê o conteúdo digitado numa IA no navegador; o agente de rede vê a conexão de qualquer aplicativo. Juntos cobrem o que cada um sozinho não alcança.

Antes de começar

  • Windows 10 ou 11, com acesso de administrador para instalar.
  • Python 3.9 ou superior instalado (o instalador cuida do pywin32 e do psutil).
  • A URL do coletor central — o servidor que recebe os eventos (ex.: http://10.211.55.2:8765).
  • Uma senha que você vai definir para proteger a pausa e a desinstalação do serviço.

Instalação em três passos

1

Copie a pasta para a máquina

Extraia o ZIP e copie a pasta GerencIA-Agente-Estacao para um local fixo, por exemplo C:\GerencIA. Não mova a pasta depois de instalar — o serviço aponta para este caminho.

2

Execute o instalador como administrador

Dê dois cliques em INSTALAR.bat. O Windows vai pedir elevação — clique Sim.

Controle de Conta de Usuário

Deseja permitir que este aplicativo faça alterações no dispositivo?

!

SimNão
3

Informe o coletor e defina a senha

O instalador pergunta a URL do coletor e, em seguida, a senha de proteção. Ele instala as dependências, registra o serviço e o inicia.

Prompt de Comando / PowerShell (elevado)URL do coletor central (ex.: http://10.211.55.2:8765): http://10.211.55.2:8765 Defina a SENHA para pausar/desinstalar o servico: ******** Python: py -3 Instalando o servico GerenciaSensor ... OK. Servico 'GerenciaSensor' instalado e rodando. Coletor: http://10.211.55.2:8765 Estado: Running
Guarde a senha. É ela que libera pausar, parar ou desinstalar o serviço. Sem ela, nem o administrador consegue pelo caminho normal. Ela é gravada apenas como hash (PBKDF2-SHA256) no registro, legível só por SYSTEM e administradores.

Ou, pelo PowerShell, dentro da pasta servico:

PowerShellPS C:\GerencIA\GerencIA-Agente-Estacao\servico> .\gerenciar-servico.ps1 -Acao status Servico: GerencIA · Sensor de Rede Estado: Running Inicio: Auto Coletor: http://10.211.55.2:8765

Operar o serviço

Sempre num PowerShell como administrador, dentro da pasta servico. O status é livre; pausar, parar e desinstalar exigem a senha.

AçãoComando
Ver situação sem senha.\gerenciar-servico.ps1 -Acao status
Pausar senha.\gerenciar-servico.ps1 -Acao pausar -Senha ****
Retomar senha.\gerenciar-servico.ps1 -Acao continuar -Senha ****
Parar senha.\gerenciar-servico.ps1 -Acao parar -Senha ****
Desinstalar senha.\gerenciar-servico.ps1 -Acao desinstalar -Senha ****  /  DESINSTALAR.bat
Sem instalar serviço (para testar). Na pasta do agente: python sensor.py testar faz uma varredura e imprime o que casou; python sensor.py rodar roda em primeiro plano (Ctrl+C encerra).

Até onde a senha protege

Honestidade importa numa entrega de governança. A trava tem camadas:

  • Usuário comum: a ACL do serviço não permite parar nem pausar. Sem chance.
  • Administrador casual: o caminho sancionado é o gerenciar-servico.ps1, que exige a senha.
  • Administrador determinado (com SYSTEM, safe mode): ainda consegue remover. Blindagem absoluta contra o próprio admin da máquina exige MDM/EDR com proteção em kernel — fora do escopo deste protótipo. A trava eleva de “qualquer um desliga” para “só quem tem a senha”.

Problemas comuns

SintomaO que fazer
“Python não é reconhecido”Instale o Python 3.9+ (marque “Add to PATH”) e rode o INSTALAR.bat de novo.
Serviço não inicia (erro 1053)Confirme que o pywin32 foi instalado; rode py -3 -m pywin32_postinstall -install como admin.
Status “Running”, mas nada no painelConfira a URL do coletor e se o servidor está no ar (-Acao status mostra a URL gravada).
Esqueci a senhaComo admin, pare pelo SCM e reinstale definindo nova senha. (Registrada só como hash — não há como recuperá-la.)
Detalhes técnicos completos — sinais de detecção, limites e arquitetura — estão em servico\LEIA-ME.md, dentro do pacote.

Em uma linha

Copie a pasta → rode INSTALAR.bat como administrador → informe coletor e senha. O serviço GerencIA · Sensor de Rede passa a subir com o Windows e a reportar o uso de IA da máquina, sem ler conteúdo, e só sai do ar com a senha.
